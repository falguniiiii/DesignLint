# DesignLint frontend

React + Vite single-page app. See the [project README](../README.md) for setup, architecture and limitations.

```bash
npm install
cp .env.example .env     # VITE_API_BASE_URL, defaults to http://localhost:8000
npm run dev              # development server
npm run build            # production build into dist/
npm run lint             # oxlint
```

There is no frontend test suite configured yet.
